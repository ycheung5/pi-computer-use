# Preserve reference behavior while implementing for Pi

Implement fresh TypeScript code for native Pi tools and Windows/WSL2 hosts, using dsh-computer-use-win 0.5.3 as the behavioral baseline. Preserve its safeguards, browser post-action observations and experimental installed-Firefox compatibility rather than changing behavior to fit a simpler browser library; simplification remains welcome where these contracts are retained. [ADR 0003](0003-exclusive-desktop-control.md) supersedes shared physical-user-input behavior for exclusive-control periods; other reference contracts remain the baseline. This trades some implementation freedom for a faithful Pi version and supersedes the proposed managed-Firefox and observation changes.
